# Screenshots

Add your in-game captures here to build the gallery referenced from the main README.
Screenshots must be taken inside Minecraft with the pack active (they cannot be produced
by the build tooling), so this folder ships empty by design.

Recommended shots (suggested file names):

| File                     | Scene                                                    |
|--------------------------|----------------------------------------------------------|
| `01_sunrise.png`         | Plains at golden sunrise — god rays through trees         |
| `02_noon_water.png`      | Ocean/lake at noon — reflections, refraction, caustics    |
| `03_sunset_clouds.png`   | Orange sunset with volumetric clouds                      |
| `04_night_aurora.png`    | Clear night — stars, Milky Way, aurora borealis           |
| `05_rain_storm.png`      | Storm — wet surfaces, ripples, dynamic fog                |
| `06_cave.png`            | Cave — cave fog, torch/block light, emissive ores         |
| `07_nether.png`          | Nether — heat haze, smoke, glowing lava                   |
| `08_end.png`             | The End — purple void sky, floating particles             |

Keep individual images under ~2 MB where possible so the repository stays lightweight.
