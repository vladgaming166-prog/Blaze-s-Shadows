# Example configuration presets

These are ready-made "looks" for **Blaze's Shadows**. They are plain option lists using
the exact identifiers from `shaders/lib/settings.glsl`.

## How to apply

**Option A — paste values in-game**
Open the shader settings menu and match the values below (fastest for a few tweaks).

**Option B — copy the config file**
OptiFine/Iris store your per-pack settings in a text file next to the pack:

```
.minecraft/shaderpacks/BlazesShadows.txt     (folder install)
.minecraft/shaderpacks/BlazesShadows.zip.txt (zip install)
```

Copy the contents of a preset below into that file (keep any lines you want to preserve),
then re-select the pack in-game to reload.

> The exact file name mirrors your pack's file/folder name. If unsure, change one setting
> in-game first — the file will appear automatically — then edit it.

## Available presets

- **Cinematic.txt** — filmic ACES look, gentle contrast, motion blur + subtle grain.
- **Realistic.txt** — neutral white balance, AgX tonemap, restrained saturation.
- **Vibrant.txt** — punchy colours, boosted bloom, warm golden hours.
- **Performance.txt** — trims the heaviest effects for high, stable FPS.
